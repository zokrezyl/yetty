# ysdf2 — generated yclass shape classes (v2 ydraw client interface)

One yclass class per SDF shape in
[ysdf](../ysdf/README.md)'s `sdf-drawables.yaml` — `ysdf2:circle`,
`ysdf2:box`, … — each deriving
[ydrawlist2](../ydrawlist2/README.md)`:shape` (the paint prefix) and
overriding the `ydrawlist2:drawable` pack slot. pack() writes the record
words straight from the schema layout
(`[type|HAS_ID][id?][z][fill][stroke][stroke_width][geometry…]`) via
`yetty_ydraw_drawable_list_add_prim` — **byte-identical** to the plain-C
`funcs.gen.c` builders, pinned by `test/ut/ydrawlist2/`.

## Provenance — read before touching anything

`shapes.c` is GENERATED by `src/yetty/ysdf/gen-sdf-code.py` (run
`uv run src/yetty/ysdf/gen-sdf-code.py`, then the repo formatter —
committed files are clang-formatted, raw generator output is not), and is *itself an input* to the
yclass codegen (`make codegen` parses its annotations into
`src/yetty/gen/{api,impl}/ysdf2/` and `model.yaml`). The chain:

```
sdf-drawables.yaml → gen-sdf-code.py → shapes.c → make codegen → glue + model.yaml → ffigen → bindings
```

Only CMakeLists.txt and this README are hand-written. The `2` suffix is
transitional (epic #712).
