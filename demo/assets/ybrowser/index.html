ybrowser

Demo pages — each link exercises one aspect of the engine. Click a card title.

CSS basics

Box model, borders, colors, custom properties (media-gated and element-scoped), floats, positioning.

Flexbox

Grow / shrink ratios, min-width floors, wrap with per-line distribution, order, row-reverse, align-self.

Grid

Track templates (px / fr / auto), column spans, gaps, row stretch, a large auto-flow grid.

Tables

Data tables and an infobox — rows, headers, zebra striping.

SVG

Inline <svg> merged as vectors, <img src=*.svg>, and data-URI SVG — no rasterization.

Images

PNG and JPEG decoding, intrinsic sizing, attribute and CSS sizing, aspect-ratio preservation.
