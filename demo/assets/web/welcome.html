Terminal Unchained — a real HTML page, laid out and painted straight into the terminal's ydraw layer.

This page carries no external resources. The headings, the table, the coloured swatches and this rounded card are all produced by the engine's own CSS box model and rasteriser — the same one that scrolls with your shell history.

Two engines, one surface

  • ynetsurf — the NetSurf 3.11 layout engine.
  • ybrowser — the lexbor DOM/CSS engine, with JS, timers and click dispatch.

Both emit one ydraw OSC envelope per render, so a page scrolls into the terminal exactly like ycat output — or, interactively, becomes a Chrome-like pane you can click and type into.
